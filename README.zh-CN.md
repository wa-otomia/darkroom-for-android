# 暗房 Darkroom

[English](README.md) · **简体中文** · [日本語](README.ja.md)

原生 Android 暗房。相机把 JPG 传进机内 FTP 收件匣，你在手机上浏览、裁成 2:3、按需做 AI 修图，
再经蓝牙 Classic SPP 打印到 **米家便携照片打印机 Pro**（KDRSHDY03HT）。全程不经过米家云。

>
> 本应用通过**社区逆向**得到的协议驱动打印机，与小米、汉图（Hannto）无任何隶属、认可或支持关系，
> 固件更新后随时可能失效或行为异常。发布本项目是作为学习与研究的参考资料，
> **请勿用于商业用途**。详见[适用范围与免责声明](#适用范围与免责声明)。

```
相机 --FTP--> 收件匣 --> 相册 --> 构图 / AI / 水印 --> RFCOMM 通道 1 --> 打印机
```

## 功能

- **相机 FTP 收件匣** —— 进程内 FTP 服务器，默认端口 **2121**（Android 上绑 21 需要 root），
  只收 JPG，被动模式，仅绑定 Wi-Fi 网卡。可选开机自启，以及保活前台服务。
- **入匣方式** —— FTP、系统相机拍摄，或从相册手动导入。
- **相册** —— 基于 Room 的图库，记录修图谱系与每张照片的多个版本，删除带倒计时撤销。
- **工作室** —— 2:3 构图，带吸附拖动与 45° 旋转吸附，构图按版本分别保存；水印叠加；
  以 2 倍尺寸导出到系统相册；分享。
- **AI 修图** —— Grok（xAI）与 OpenAI 两家收敛到同一套接口，提供提示词预设（人像 / 创意 / 自定义）。
  可为当前照片生成新版本，也可直接在相册里生成一张独立照片。
- **水印** —— SNS 账号（Instagram / X / Facebook / 微博）与日期，竖版与横版分别记录位置，
  只在打印和导出时才渲染进图像。
- **打印** —— 打印队列，逐任务进度、份数、填满/留白、取消，以及缺纸检测。
  输出 1040 × 1560、2:3，对应打印机 313 dpi 的 2×3 英寸相纸。
- **自动化** —— 入匣 → AI 修图 → 水印 → 打印，每一步都可单独开关。
- **多语言** —— English、简体中文、日本語、한국어。

API key 与 FTP 密码存放在 `EncryptedSharedPreferences`，不会以明文落盘。

## 构建

需要 JDK 17 和 Android SDK（`compileSdk` 37）。

```bash
./gradlew :app:test :app:assembleDebug
```

用 Android Studio 打开本目录，或设置 `ANDROID_HOME` 后直接跑 Gradle。
`local.properties` 有意不纳入版本库 —— Android Studio 首次打开时会自动生成，
也可以自己写一行 `sdk.dir=/path/to/Android/sdk`。

| | |
|---|---|
| minSdk / targetSdk / compileSdk | 29 / 37 / 37 |
| 应用 ID | `app.darkroom.android` |
| 技术栈 | Kotlin、Jetpack Compose、Room、Hilt、OkHttp、Coil |

## 打印机

| | |
|---|---|
| 设备 | 小米 / 米家便携照片打印机 Pro |
| 型号 | KDRSHDY03HT |
| 通路 | 蓝牙 Classic SPP / RFCOMM，通道 1 |
| 数据 | baseline JPEG，1040 × 1560，按 988 字节分片发送 |
| 会话 | Diffie–Hellman 握手，之后 AES-128-ECB |

打印链路不需要米家账号，也不需要设备 token：AES 密钥是每次会话现协商出的 Diffie–Hellman 共享秘密。
先在 Android 系统蓝牙设置里配对打印机，再到应用的设置页绑定。

只在 Pro 上验证过。小米其它型号的照片打印机帧格式不同，不受支持。
