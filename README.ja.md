# Darkroom（暗室）

[English](README.md) · [简体中文](README.zh-CN.md) · **日本語**

Android ネイティブの暗室アプリ。カメラが端末内の FTP 受信箱へ JPG を送り、それを閲覧して
2:3 にトリミングし、必要なら AI 加工をかけたうえで、Bluetooth Classic SPP 経由で
**Xiaomi ポータブルフォトプリンター Pro**（KDRSHDY03HT）に印刷します。Mi Home クラウドは一切経由しません。

```
カメラ --FTP--> 受信箱 --> ギャラリー --> 構図 / AI / 透かし --> RFCOMM ch.1 --> プリンター
```

## 機能

- **カメラ FTP 受信箱** —— プロセス内 FTP サーバー。既定ポートは **2121**（Android で 21 番を
  使うには root が必要）。JPG のみ、パッシブモード、Wi-Fi インターフェースのみにバインド。
  自動起動と、常駐用のフォアグラウンドサービスも選べます。
- **取り込み** —— FTP、標準カメラでの撮影、フォトピッカーからの手動インポート。
- **ギャラリー** —— Room ベースのカタログ。編集の系譜と写真ごとのバージョンを保持し、
  削除はカウントダウン付きで取り消せます。
- **スタジオ** —— スナップドラッグと 45° 回転スナップによる 2:3 の構図調整（構図はバージョンごとに保存）、
  透かしのオーバーレイ、2 倍サイズでのギャラリー書き出し、共有。
- **AI 加工** —— Grok（xAI）と OpenAI を共通のインターフェースにまとめ、
  プロンプトのプリセット（ポートレート / クリエイティブ / カスタム）を用意。
  写真の新しいバージョンとして生成するか、ギャラリーに独立した 1 枚として生成できます。
- **透かし** —— SNS アカウント（Instagram / X / Facebook / Weibo）と日付。
  縦向きと横向きで位置を別々に保持し、印刷と書き出しのときだけ画像に焼き込みます。
- **印刷** —— 印刷キュー、ジョブごとの進捗、部数、フィル / フィット、キャンセル、用紙切れ検出。
  出力は 1040 × 1560 の 2:3 で、プリンターの 313 dpi・2×3 インチ用紙に対応します。
- **自動化** —— 取り込み → AI 加工 → 透かし → 印刷。各ステップを個別にオン / オフできます。
- **多言語対応** —— English、简体中文、日本語、한국어。

API キーと FTP パスワードは `EncryptedSharedPreferences` に保存され、平文では残りません。

## ビルド

JDK 17 と Android SDK（`compileSdk` 37）が必要です。

```bash
./gradlew :app:test :app:assembleDebug
```

このディレクトリを Android Studio で開くか、`ANDROID_HOME` を設定して Gradle を直接実行してください。
`local.properties` は意図的にコミットしていません。Android Studio が初回起動時に生成しますが、
`sdk.dir=/path/to/Android/sdk` と自分で書いても構いません。

| | |
|---|---|
| minSdk / targetSdk / compileSdk | 29 / 37 / 37 |
| アプリケーション ID | `app.darkroom.android` |
| 技術構成 | Kotlin、Jetpack Compose、Room、Hilt、OkHttp、Coil |

## プリンター

| | |
|---|---|
| 機種 | Xiaomi / Mijia ポータブルフォトプリンター Pro |
| 型番 | KDRSHDY03HT |
| 通信 | Bluetooth Classic SPP / RFCOMM、チャンネル 1 |
| データ | ベースライン JPEG、1040 × 1560、988 バイト単位で分割送信 |
| セッション | Diffie–Hellman ハンドシェイク後に AES-128-ECB |

印刷経路に Mi Home アカウントもデバイストークンも不要です。AES 鍵はセッションごとに
Diffie–Hellman で共有する秘密鍵です。まず Android の Bluetooth 設定でプリンターとペアリングし、
そのうえでアプリの設定画面からバインドしてください。

動作確認は Pro のみです。Xiaomi の他のフォトプリンターはフレーム形式が異なり、対応していません。
